# App Artwork

`YourOwnWeigh-scale-teal.png` is the original smiling-scale artwork. The web app serves its derived icon from `server/static/`. `YourOwnWeigh-icon-1024.png` is the 1024px source used by the Apple Health Shortcut's optional Home Screen icon.

`strip_metadata.py` removes ancillary text/EXIF metadata from PNGs without changing compressed pixel data, colour profiles or provenance chunks.
